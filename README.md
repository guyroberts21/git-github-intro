# Git & GitHub: A Safety Net for Collaborative Work

A 30-minute introduction to Git and GitHub for technical and non-technical audiences.

## Editing the slides
All the wording lives in **`slides.md`**. Edit it, commit, and the site rebuilds and republishes itself
(see the Actions tab). You can edit it straight in the browser: open the file on GitHub and press the pencil icon.
The instructions for the format are in the comment at the top of the file.

Layout, colours and fonts live in `deck.css` and `template.html`, so you don't need to touch them for wording changes.

## Previewing locally
```bash
python3 build.py        # writes _site/index.html
open _site/index.html   # macOS; or just double-click the file
```

## Using the slides
Arrow keys, space or the on-screen buttons move between slides. `F` is full screen. Add `#5` to the address to open slide 5.
Print to PDF from the browser for one slide per page.
